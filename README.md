# Idle Rats Roster

A one-page character roster for **Idle Rats**, the idle auto-battler by SkaRift. All 55 rats with their portraits, roles, elements, starting stars, skills and leader auras. Tap any rat to open their file.

## Publish with GitHub Pages
Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main**, folder **/ (root)** → Save. The site appears at `https://skarift.github.io/IdleRatsRoster/` after a minute or two.

## Updating
- Character text and skills live in the `RATS` list near the bottom of `index.html`.
- Portraits are in `img/` (360×360 WebP, file name = character name in lower case with underscores).
